# Security

Do not post passwords, signing keys, backup files, or personal financial records in public issues.

For a suspected security vulnerability, use GitHub's private vulnerability reporting on this repository when available. Include reproduction steps using fictional data, the affected version, and the potential impact. For ordinary bugs, use the public issue tracker without sensitive details.

Use the latest published Windows version. macOS is not currently a supported release platform.

Updater packages are verified using Tauri's update signatures. These signatures are distinct from Authenticode publisher signing; the current Windows installer does not have an Authenticode certificate. SHA-256 checksums are included with release assets.
